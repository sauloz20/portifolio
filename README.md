# Portfólio — Saulo Gabriel

![HTML](https://img.shields.io/badge/linguagem-HTML-blue)

Página pessoal de portfólio com apresentação, projetos, experiência e contato.

## Tecnologias

HTML, CSS e JavaScript em um único arquivo. A fonte Poppins e as imagens dos projetos são carregadas externamente.

## Executar

Use um navegador moderno. Com Git e Python 3 instalados, execute:

```sh
git clone https://github.com/sauloz20/portifolio.git
cd portifolio
python -m http.server 8000
```

Abra `http://localhost:8000/`. Uma conexão à internet é necessária para carregar a fonte e as imagens externas.

## Estrutura

- `index.html`: conteúdo, estilos e interações da página.

## Observações

O botão de download do currículo usa `href="#"` e não aponta para um arquivo PDF neste repositório. Os links de demonstração e dados profissionais devem ser revisados antes da publicação.
